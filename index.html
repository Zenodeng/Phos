Phos —
把 RAW 修图做成一件工整的事

macOS 原生非破坏性 RAW 照片编辑器。全部像素处理跑在 GPU 上，编辑写入原图旁的副档，原始文件一个字节都不会被修改。本页展示 Phos Studio 的界面设计：石墨 × 香槟金。

Design Language

石墨 × 香槟金

界面以中性石墨灰面板打底，香槟金只点在「选中」与「编辑态」两处，其余全部克制。工整来自严格网格：固定行高节奏、tabular 数字对齐、发丝分隔线、中英双语的大写字距节标题。浅色主题换墨黑主按钮 + 深金，明暗双主题跟随系统。

克制的金色

金色不装饰，只表达状态：选中环、滑杆填充、胶片 LUT 卡、导出主按钮。看到金色，就是在编辑。

26 / 27 / 34px 固定行高节奏，16px 统一内边距，9.5px 大写字距微标签，数值列右对齐等宽。密度高而不乱。

Capabilities

功能概览

「把高频能力做全做透」而非堆砌功能。所有调整写入原图旁的副档（.rawforge.json），原始文件永不修改。

RAW 解码

ARW / CR3 / NEF 等主流 RAW，另支持 HEIF / HEIC / HIF、JPEG、PNG、TIFF、AVIF。

影调与色彩

曝光、对比、高光、阴影、白平衡灰点吸管、色调曲线、HSL 混色、颜色分级、校准。

胶片 CLUT 模拟

HALD CLUT 加载（含 Kodak 2383 / 2393 印片模拟），64³ 立方体重采样，强度可调。

局部蒙版

笔刷、线性 / 径向渐变、颜色范围、亮度范围、深度蒙版；蒙版可叠加与擦除。

批量工作流

多选同步调整、恢复快照、命名预设、命名快照、多重曝光合成。

专业导出

8 / 16 位 TIFF 多色域、长边缩放、文字 / 图片水印九宫格叠加、固定导出目录。

Honest Comparison

Phos vs Lightroom Classic
An honest comparison

Both are serious RAW tools, built around different trade-offs. Here is where each one fits best.

Dimension Phos (v4.7.1) Adobe Lightroom Classic
Pricing & License Free & open source (MIT). No account, no subscription, no paid tier. Paid monthly/annual subscription requiring an Adobe account and periodic online check-ins.
Files & Privacy Folder-based with sidecars (.rawforge.json + bidirectional Adobe .xmp). No locked catalog; photos never leave your Mac. Centralized catalog database built for very large multi-drive commercial archives and optional cloud sync.
Color & Tone Engine 16-bit extended linear Metal (20 compute kernels), EDR/HDR preview, AgX rolloff, OKLCH Point Color, 303 film CLUTs and LR .xmp preset import (0–200%). Mature Camera Raw engine with broader commercial camera profiles, Print/Book modules and third-party plugin ecosystem.
Masks & On-Device AI Zero-Python out of the box: boolean sub-masks, 8-part portrait & sky segmentation, Reference Color Match, any-RAW monocular depth bokeh, LaMa remove, RAW denoise & 2x Super Res (5-slot Core ML Hub). Polished commercial Adobe AI Denoise, Generative Remove (cloud-assisted) and fine portrait masking ready out of the box.
Culling & Footprint 8.8 MB native Swift/AppKit app; Grid/Compare/2–4 Up Survey/Reference views, Smart Culling (eyes, sharpness, bursts) and bilingual semantic search. Built for tens-of-thousands-photo DAM catalogs, live camera tethering and complex smart collections / publish services.
Platforms & Signing Focused on macOS 26+ Apple silicon (separate experimental Windows port, no iPad app yet). Ad-hoc signed — requires one-time macOS approval. Full ecosystem across macOS, Windows, iPad, iPhone and Web, with official notarized builds.

If you rely on cross-platform cloud sync, camera tethering or massive commercial catalogs, Lightroom Classic remains the established standard. If you want a fast, subscription-free, folder-based Apple-silicon RAW studio with 16-bit Metal rendering and on-device AI, Phos is built for that workflow.

A few things to know

Is Phos free?

Free and open source under the MIT license. No subscription, no in-app purchases, no account, and no “Pro” tier.

Which macOS versions and Macs are supported?

macOS 26.0 or later on an Apple-silicon (M-series) Mac. Since 3.2.5 the minimum is 26.0, up from 15.0; on older systems, keep using 3.2.4. Only Apple-silicon builds are provided — Intel Macs aren’t supported yet.

Which cameras’ RAW files are supported?

Phos uses macOS’s built-in RAW decoding (Core Image and ImageIO), so any RAW file that Preview can open can be edited — including mainstream formats from Canon (CR2 / CR3), Nikon (NEF), Sony (ARW), Fujifilm (RAF), and Adobe DNG.

Support for newer cameras depends on whether the macOS version you’re running already includes a decoder for that model.

Are my photos uploaded? What is the network used for?

No. Photos are processed entirely on your Mac — no cloud, no account, no telemetry.

The only network activity is a single check of the latest version number at launch; the request contains nothing about you, your photos, or this Mac.

How is it different from Lightroom?

Phos is local-first and open source: no subscription, no locked catalog, no forced cloud sync. Open any folder on a 16-bit extended linear Metal/EDR pipeline with OKLCH Point Color, composite boolean & 8-part portrait masks, and zero-Python on-device AI (Reference Color Match, monocular depth bokeh, LaMa remove, 2x Super Res).

It also reads and writes bidirectional Adobe XMP sidecars and imports Lightroom .xmp presets (0–200% strength), built for personal workflows where photos stay entirely on your Mac.

What if macOS blocks Phos on first launch?

This is the standard prompt every app without Apple notarization gets — not something specific to Phos. Double-click Phos → click “Done” → open System Settings → Privacy & Security → scroll to the bottom and click “Open Anyway”.

You can also run xattr -dr com.apple.quarantine /Applications/Phos.app in Terminal to remove the quarantine flag for good.

Does it support batch processing?

Yes. Grid (G), Compare (C), 2–4 Up Survey (N) and Reference (⇧R) views pair with on-device Smart Culling (eye-closure, sharpness, burst best), bilingual semantic search, Virtual Copies, multi-select adjustment sync and bounded-concurrent batch export (including 2x Super Res and watermarks).

Is there a Windows or iPad version?

The macOS app is the primary platform. Windows has a separate experimental port (4.4.0, ported from the macOS 4.4.0 source), maintained separately from macOS: Apple’s Vision and Core Image are replaced with local implementations, on-device AI needs a one-time base-model download prepared in-app, and it isn’t code-signed. It’s available from the downloads section.

An iPad version is still being assessed for feasibility, with no releasable timeline.

How can I report issues or contribute?

File an Issue or a Pull Request at the GitHub repository. The project is written in Swift, built on Metal, Core Image, Vision, Core ML, and AppKit.

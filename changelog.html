v4.7.1

当前最新 · 热修复
2026-11-24GitHub Release ↗

修复蒙版布尔子蒙版菜单在 macOS 26/27 下的符号名退化与右侧检视器左边界裁切问题。

  • 蒙版布尔菜单改用原生 NSMenu 图标按钮：替换「布尔子蒙版」添加组及子蒙版行运算切换处的 SwiftUI .borderlessButton 纯图标菜单，根治退化渲染为符号名文本（plus.square / minus.square / square.on.square）并撑破检视器的问题。
  • 加固检视器左对齐宽度约束：在 GroupBox、InspectorPane 滚动视口、MaskPane 与 MaskEditingControls 锁定左对齐与紧凑宽度，确保 248pt–304pt 宽窄面板均无裁切。
  • 细节清理与翻译补齐：移除自动影调场景与参考视图菜单内的冗余双重下拉箭头；补齐「减去 / Subtract」「交叉 / Intersect」，中英 UI 词条增至 1,017 条并全校验通过。

v4.7.0

端侧 AI 跃升
2026-11-23GitHub Release ↗

零 Python 端侧 AI 全家桶落地：参考图反解可调参数、任意 RAW 单目深度光学散景、RAW 域降噪与 2x 超分、智能挑片与 5 槽位模型中心。

  • 参考图 → 全可编辑参数反解：基于 OKLab/OKLCH 7 分位亮度、三段色彩分级、8 色域 HSL 与坐标下降，一键把任意参考片反解为可调 Phos 参数，支持 0%–150% 强度与肤色保护。
  • 任意 RAW 单目深度与物理光学散景：内置 Vision 显著性 + 人物 + 透视梯度零模型深度与可选 Core ML DepthAnythingV2，支持画布点击采样焦平面、深度热力图、5–8 边形光圈叶片、线性 HDR 高光光斑增益与猫眼旋焦。
  • 非破坏性 RAW 域降噪与导出 2x 超分：Metal 线性 YCoCg 保边降噪搭配导出端 Lanczos 2x + 结构张量锐化（或可选分块 Core ML 权重），保持预览 1:1 像素契约且零中间 DNG。
  • 端侧智能挑片、连拍聚类与双语语义搜图：Vision 眼睑 EAR 闭眼检测、焦点锐度评分、连拍最佳帧聚类与视觉相似图排序。
  • 纯 Swift 原生 AI 工坊与 5 槽位模型中心：内置 NativePhotoPlanner 与统一 Core ML 模型中心（lama / sky / depth / denoise / superRes）；同步修复 PointColorPane 删除色样时的 SwiftUI 越界崩溃。

v4.6.0

蒙版、选片与 XMP
2026-11-23GitHub Release ↗

补齐人像 8 部位分割、画笔自动边缘吸附、全画布多视图选片、双向 Adobe XMP 与 82 支内置镜头配置。

  • 蒙版完备化：新增身体皮肤、眉毛、衣服分割，升级零模型与 Core ML 天空分割；画笔新增 Auto Mask 自动边缘吸附与数位板压感；布尔子蒙版支持单独点击选中、切换加/减/交与画布拖动，局部面板新增色调/白黑、可展开曲线编辑器与局部点颜色。
  • 修补画布交互：自动干净源点推荐、画布直接拖动修补中心与源点手柄、双环悬停画笔预览及 H / Delete 快捷键。
  • 多视图选片：新增网格（G）、双图对比（C）、2–4 图同屏（N）与参考视图（⇧R），图库支持递归子目录、关键词与相机/镜头筛选。
  • XMP 与 82 支镜头：完整双向 Adobe XMP 旁档（支持持久化自动同步）、Lightroom .xmp 预设导入与 0%–200% 强度滑块；内置镜头数据库扩展至 82 组配置。

v4.5.0

16-bit Metal 引擎
2026-11-22GitHub Release ↗

底层全面升级为 16-bit 扩展线性浮点 Metal 计算管线与 EDR/HDR 预览，引入 OKLCH 点颜色、LaMa 消除与 HDR 导出。

  • 16-bit Metal / EDR 管线：切换至 extendedLinearSRGB / .RGBAh 线性浮点管线与 EDR 直通预览画布，加入 J 键高光/阴影溢出警示。
  • 专业影调与色彩：新增 AgX 对比中心与高光滚降、Guided Filter 14-stop 保边影调、双向黑白场、OKLCH 空间 HSL、独立点颜色吸管与银盐颗粒粗糙度。
  • 无痕修补与元数据导出：引入 Heal（泊松融合）、Clone、Remove（4 层 PatchMatch + 可选 Core ML Big-LaMa）；支持 EXIF/IPTC 保留、移除 GPS 隐私及 Gain-Map HDR JPEG / 10-bit PQ HEIC / 16-bit Display P3 导出。

v4.4.0

镜头校正与后台 LUT
2026-10-31GitHub Release ↗

镜头校正支持校正前后实时对比与 8 等分参考网格，LUT 扫描移至后台，官网与更新清单迁至 zenodeng.com。

  • 镜头校正体验：新增「校正前后」一键对比与 8 等分直线网格，明确标注配置来源与缺失标定项，随包内置首批镜头配置文件。
  • 后台 LUT 扫描：将胶片 LUT 目录遍历移入后台线程，切换面板与刷新不再阻塞主线程交互。

v4.3.0 / v4.2.0

双语与液态玻璃工作区
2026-10-21 – 10-22GitHub Release ↗

支持跟随系统 / 简体中文 / English 即时切换，统一 macOS 26 原生液态玻璃工作区与四边整段可拖裁剪、Vision 自动水平。

  • 即时双语切换：无需重启、不重建编辑状态或历史，菜单、参数与无障碍标签即时跟随语言切换。
  • 原生玻璃与交互打磨：A/B 侧栏与胶片条全面接入原生玻璃（减少透明度时自动回退实色），裁剪框四边整段可拖并加入本地 Vision 自动水平拉直。

v4.1.0 / v4.0.0

新工作区与本地 VLM

重构主窗口为 A 沉浸编辑 / B 连续选片双布局，并上线带 P2 微调适配器（1.3 MB）的可选本地 Qwen3-VL MLX 修图模式。

  • A / B 双布局工作区：列表精修与底部胶片条选片共享同一份编辑状态与撤销栈，支持浅色 / 深色双外观图标。
  • 可选本地多模态模型：接入本机 127.0.0.1 MLX 推理与 SHA256 文件完整性校验，并随安装包提供国内镜像脚本 国内网络安装.command。

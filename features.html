明暗与白平衡

从整体亮度到局部层次，按照片的需要逐步调整。

  • 色温、色调与灰点吸管；曝光、对比、高光、阴影、白色和黑色。
  • 纹理、清晰度、去朦胧、鲜艳度、饱和度，以及 HDR 压高光与拉暗部。
  • 自动影调提供可继续手动调整的起点；原图对照和撤销始终可用。
补充规格与说明

曝光、对比、高光、阴影、白色与黑色、纹理 / 清晰度 / 去朦胧、白平衡灰点吸管、HDR；五通道色调曲线、HSL 混色、颜色分级、黑白、校准。

曲线与色彩

既能建立统一色调，也能处理一个颜色的微小偏差。

  • RGB 合成、亮度、R / G / B 五通道曲线；可自由添加与移动控制点。
  • 阴影、中间调、高光三档颜色分级；混合与平衡控制分界。
  • 八个色相区间的 HSL 混色、黑白通道混合与原色校准。
补充规格与说明

胶片与质感

把色彩风格留成可重复使用的选择。

  • HALD 胶片 LUT 及 Kodak 2383 / 2393 等印片模拟，强度连续可调。
  • 支持导入 .cube LUT，也能扫描自备 HaldCLUT 目录。
  • 颗粒与颗粒尺寸、暗角、光晕、锐化和亮度 / 色彩降噪。
补充规格与说明

HALD CLUT 加载，含 Kodak 2383 / 2393 印片模拟，64³ 立方体重采样，强度可调。

九种局部蒙版

让想调整的区域拥有自己的参数。

  • 线性渐变、径向渐变、画笔、颜色范围、亮度范围。
  • 选择主体、选择人物、主体抠图与深度涂绘，结合本机视觉能力。
  • 每个蒙版都有独立调整栈，可反转、复制、删除；画布参考线与控制点可直接操作。
补充规格与说明

线性与径向渐变、画笔、颜色范围、亮度范围、选择主体、选择人物、主体抠图、深度涂绘，共九种。每个蒙版带独立调整栈，可反转、复制、删除。

裁剪、几何与镜头

先照顾构图，再照顾边缘。

  • 八个裁剪手柄、画幅比例、90° 旋转、水平镜像与手动拉直。
  • 自动水平、自动与手动透视校正，裁切与旋转操作可撤销。
  • 横向色差与紫边抑制；人物深度数据或深度涂绘可用于焦外散景。

选片、预设与批量

让一张照片的好调整，延续到同一组照片。

  • A 沉浸编辑与 B 连续选片共享编辑状态，支持搜索、评分与标记。
  • 保存命名预设、命名快照、恢复快照，多选同步调整与批量导出。
  • 多重曝光平均、曝光融合、手持降噪等合成工作流。
补充规格与说明

多选同步调整、恢复快照、命名预设、命名快照，以及多重曝光合成。

4.0 重做的主窗口：A 列表逐张精修，B 胶片连续选片。工具条与系统交通灯共用中线，列表与检查器宽度可拖，切布局不打断编辑。

导出与水印

把照片交到下一步，格式由你决定。

  • JPEG、PNG、TIFF、HEIC 等输出；TIFF 支持 8 / 16 位与多色域。
  • 长边缩放、输出质量、输出锐化，以及文字或图片水印。
  • 水印支持九宫格位置、透明度和旋转，可固定导出目录。
补充规格与说明

8 位与 16 位 TIFF 多色域、长边缩放、文字与图片水印九宫格叠加、固定导出目录。

本地 AI 修图

自然语言提出要求，参数仍然可以继续编辑。

  • 可生成全局调整与局部蒙版建议；先看双图预览，再决定是否应用。
  • 明确保留的滑杆受到约束；照片或参数变化后，过期建议不直接应用。
  • 约 3.1 GB 的底模单独安装，约 1.3 MB 的适配器随应用提供。实验性能力，以预览为准。
补充规格与说明

用中文描述想怎么改，模型给出全局滑杆与局部蒙版建议，先预览再应用。推理在本机完成，照片不上传。属实验性功能，模型需单独安装。

开发验证与行为约束（非独立测试）

4.1 换上了新的微调权重：同一批 301 条受控验证指令上，首次严格完成率从 51.8% 提升到 94.0%。换的只是随应用附带的 1.3 MB 适配器，底模不用重新下载。这组成绩来自开发验证集，不是独立测试，也不代表审美。

说清楚就照做

「只裁去左右各 5%、保留完整高度」这类要求由代码直接计算范围，不交给模型估。自动裁切会先验证尺寸与保留面积，方案不合法就退回重试一次，两次失败不应用。

说保留就真的保留

明确要求「别动曝光」「白平衡保持原样」时，这些滑杆会从模型可写字段里移除，解码后再复核一次。全局与局部混合的要求照样支持。

先看，再决定

生成的方案先出预览，确认后才写入；一次应用对应一次撤销。局部效果会用真实渲染像素核对方向，不符合要求会重试或拦截。

原生、语言与文件

与 Mac 的工作方式保持一致。

  • Swift、Core Image、Vision 与 AppKit；浅色和深色外观可跟随系统。
  • 界面支持跟随系统、简体中文和 English，参数与菜单即时切换。
  • 编辑写入原片旁档，旧 RawForge 旁档与已有预设保持兼容。
补充规格与说明

ARW / CR3 / NEF 等主流 RAW，另支持 HEIF / HEIC / HIF、JPEG、PNG、TIFF、AVIF。

界面语言可选「跟随系统 / 简体中文 / English」，即时切换、不用重启。菜单、参数、表单与提示共 668 条词条，工具提示与无障碍标签也会跟着变。

非破坏性 RAW 照片编辑器，为 macOS 而写。所有像素处理都跑在你的 Mac 上，编辑结果写入原图旁的副档，原始文件一个字节都不会被改动。4.0 重做了整个工作区，并加入可选的本地 AI 修图。

石墨与香槟金

界面以中性石墨灰面板打底，香槟金只点在「选中」与「编辑态」两处，其余全部克制。工整来自严格网格：固定行高节奏、等宽数字对齐、发丝分隔线。

克制的金色

金色不装饰，只表达状态：选中环、滑杆填充、胶片卡、导出主按钮。看到金色，就是在编辑。

严格网格

26 / 27 / 34 px 固定行高节奏，16 px 统一内边距，数值列右对齐等宽。密度高而不乱。

蒙版可视化

参考线是 1 px 白色虚线，控制点用颜色区分职责：线性渐变端点为青、中心为白、旋转柄为琥珀；径向渐变为黄。看到颜色就知道能拖什么。

端点：控制渐变宽度
中心：整条平移
旋转柄：改变方向
径向渐变：椭圆与羽化边界

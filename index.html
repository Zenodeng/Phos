先回答几个问题

Phos 收费吗？

免费，开源，采用 MIT 协议。没有订阅、没有内购、不需要注册账号，也不存在「专业版」的区分。

支持哪些 macOS 版本和机型？

需要 macOS 26.0 或更高版本，且是 Apple 芯片（M 系列）的 Mac。3.2.5 起最低系统从 15.0 提高到 26.0，旧系统请继续使用 3.2.4。当前只提供 Apple 芯片构建，Intel 机型暂不支持。

支持哪些相机的 RAW 文件？

走 macOS 系统内置的 RAW 解码（Core Image 与 ImageIO），凡是系统「预览」能打开的 RAW 都能编辑 —— 覆盖佳能 CR2 / CR3、尼康 NEF、索尼 ARW、富士 RAF、Adobe DNG 等主流格式。

更新的机型能否支持，取决于你所用的 macOS 版本是否已内置该机型的解码器。

会上传我的照片吗？联网是做什么的？

不会上传。照片全程在本机处理，没有云端、没有账号、没有遥测。

唯一的联网行为是启动时向官网查一次最新版本号，请求里不含任何关于你、你的照片或这台 Mac 的信息。

和 Lightroom 有什么不一样？

Phos 是纯本机开源方案：不订阅、不建闭源图库、不强制云同步。打开文件夹即可在 16-bit 线性浮点 Metal/EDR 管线上编辑 RAW，支持 OKLCH 点颜色、复合布尔与 8 部位人像蒙版、零 Python 端侧 AI（参考图反解对色、单目深度物理散景、LaMa 消除、2x 超分）。

同时支持双向读写 Adobe XMP 旁档并直接导入 Lightroom .xmp 预设（0%–200% 强度），适合希望照片完全留在自己机器上的个人摄影流程。

第一次打开被 macOS 拦住了怎么办？

这是所有未做 Apple 公证的应用都会遇到的统一提示，不是 Phos 独有的问题。双击 Phos → 点弹窗里的「完成」→ 打开「系统设置 → 隐私与安全性」→ 滚到底部点「仍要打开」。

也可以在「终端」执行 xattr -dr com.apple.quarantine /Applications/Phos.app 一次性去掉隔离标记。

支持批量处理吗？

支持。提供网格（G）、双图对比（C）、2–4 图同屏（N）与参考视图（⇧R），配合端侧智能挑片（闭眼/跑焦/连拍检测）、双语语义搜图、虚拟副本、多选同步调整与并发批量导出（含 2x 超分与水印）。

有 Windows 或 iPad 版吗？

macOS 版是主线。Windows 另有一个实验性移植版（4.4.0，从 macOS 4.4.0 的源码移植），与 macOS 分开维护：Apple 的 Vision 与 Core Image 换成了本地实现，本地 AI 需自行下载底模后在软件内一键准备，也未做代码签名。可以在 下载区 获取。

iPad 版仍在可行性评估阶段，没有可发布的时间表。

怎么反馈问题或参与开发？

到 GitHub 仓库提 Issue 或 Pull Request 都可以。项目用 Swift 编写，基于 Metal、Core Image、Vision、Core ML 与 AppKit。

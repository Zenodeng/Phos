明暗、16-bit Metal 与 EDR

全程在 16-bit 扩展线性浮点 Metal 管线中推演影调，让每一档高光与暗部都保持自然过渡。

  • 16-bit 扩展线性浮点管线（extendedLinearSRGB / .RGBAh，20 个 Metal Compute 内核）与 EDR / HDR 直通预览画布。
  • AgX 对比中心与高光滚降、14-stop Guided Filter 保边高光/阴影、双向黑白场，以及快捷键 J 高光/阴影溢出警示。
  • 色温、色调与灰点吸管，纹理/清晰度/去朦胧，搭配场景识别自动影调作为可继续微调的起点。
补充规格与说明

全局 16-bit 半精度浮点线性渲染（支持自动回退 CGImage 预览），涵盖曝光、AgX 对比与高光滚降、Guided Filter 保边影调与去朦胧、双向黑白场、白平衡灰点吸管与实时溢出警示（J）。

曲线、点颜色与参考图对色

既能建立统一电影色调，也能在 OKLCH 空间精确锁定一个色相或一键反解参考片风格。

  • RGB 合成、亮度、R / G / B 五通道曲线（支持展开大图精调），以及阴影、中间调、高光三段颜色分级。
  • OKLCH 感知均匀空间的 8 色段 HSL 混色、独立点颜色（Point Color）吸管色板（色相/彩度/明度/容差独立调控）、黑白通道混合与原色校准。
  • 参考图 → 全可编辑参数反解：导入任意参考片，基于 OKLab/OKLCH 统计与坐标下降自动匹配为完全可调的 Phos 参数，支持 0%–150% 强度滑块与肤色保护。
补充规格与说明

胶片、AI 降噪超分与无痕消除

把胶片质感、无痕修补与非破坏性 RAW 降噪超分整合进同一条 GPU 管线。

  • 303 种 HALD 胶片 CLUT（含 Kodak 2383 / 2393 印片模拟）、.cube 导入与后台扫描，配银盐颗粒粗糙度、暗角与光晕。
  • Heal / Clone / Remove 无痕消除：支持泊松融合、自动干净源点推荐与画布拖动编辑，消除工具内置 4 层 PatchMatch 并支持离线 Core ML Big-LaMa（LaMa.mlmodelc）。
  • 非破坏性 RAW 域降噪与导出 2x 超分：Metal 线性 YCoCg 保边降噪，搭配导出端 Lanczos 2x + 结构张量锐化（或可选分块 Core ML 神经降噪 / 2x 超分），不生成臃肿中间 DNG 且保持预览 1:1 像素契约。
补充规格与说明

HALD CLUT 64³ 立方体重采样与浓度调节；修补面板支持 H 键显隐标记、Delete 删除选中斑点与双环画笔预览；Core ML 神经降噪 / 2x 超分支持 512×512 Hann 窗无缝分块推理。

复合蒙版与 AI 分割

用加、减、交布尔组合与语义分割，让每一个局部都拥有独立调色栈。

  • 线性渐变、径向渐变、颜色范围、亮度范围，以及支持 Auto Mask 自动边缘吸附与数位板压感的画笔。
  • AI 语义分割：选择主体、选择人物、选择背景、前景透明抠图、升级零模型/Core ML 天空分割，以及 8 部位人像分割（面部皮肤、身体皮肤、眼睛、眉毛、嘴唇、牙齿、头发、衣服）。
  • 支持加 / 减 / 交布尔子蒙版与全分辨率 Guided Filter 边缘精修；每个蒙版内置完整影调滑杆、可展开局部曲线编辑器、局部 OKLCH 点颜色与局部 LUT。
补充规格与说明

所有布尔子蒙版均可单独点击选中、切换加/减/交运算符、反转、开关并在画布直接拖动手柄；天空分割内置 Vision 地平线倾角 + 梯度阻断 BFS 零模型方案，并可在模型中心按需加载 SkySegmentation Core ML 模型。

裁剪、镜头校正与单目深度光学散景

先照顾构图与光学几何，再用真实物理散景塑造景深层次。

  • 八手柄裁剪、画幅比例、90° 旋转、水平镜像、自动水平与自动/手动透视校正，操作全程可撤销。
  • 82 支内置镜头配置与外部 Lensfun XML 导入，支持畸变/暗角校正、横向色差与紫边抑制、校正前后对比与八等分参考网格。
  • 任意 RAW 单目深度与物理光学散景：无需 iPhone 人像数据即可生成深度图（内置 Vision 显著性+人物+透视梯度零模型，或可选 Core ML DepthAnythingV2），支持画布点选对焦平面、深度热力图、圆形及 5–8 边形光圈叶片、线性 HDR 高光光斑增益与猫眼旋焦。

多视图选片、智能挑片、搜图与 XMP

从成百张连拍中快速挑出好片，把一套风格无缝延续到整个系列与既有生态。

  • A 沉浸 / B 连续选片双布局，加上全画布网格（G）、双图对比（C）、2–4 图同屏（N）与参考视图（⇧R），支持同步缩放/平移、虚拟副本、递归子目录与按相机/镜头/关键词筛选。
  • 端侧智能挑片与双语语义搜图：自动识别人像闭眼（EAR）、焦点锐度与连拍最佳帧，支持中英双语概念搜图与视觉相似图排序。
  • 双向 Adobe XMP 与 Lightroom 预设：双向读写 XMP 旁档（星级/淘汰/精选、影调、HSL、曲线、颜色分级、裁剪等）并支持持久化自动同步；直接导入 Lightroom .xmp 预设，支持悬停预览与 0%–200% 预设强度调节，以及命名快照、同步调整与多重曝光合成。
补充规格与说明

多选同步调整、恢复快照、命名预设、命名快照，以及多重曝光合成。

4.0 重做的主窗口：A 列表逐张精修，B 胶片连续选片。工具条与系统交通灯共用中线，列表与检查器宽度可拖，切布局不打断编辑。

HDR / 广色域导出与水印

把照片交到下一步，动态范围、位深、元数据与水印全由你决定。

  • 支持 Gain-Map HDR JPEG、10-bit Display P3 PQ HEIC，以及 8/16 位 Display P3 / Adobe RGB / sRGB TIFF 与 PNG。
  • 支持导出端 2x 超分辨率、长边缩放、输出质量、输出锐化与前景透明背景抠图导出。
  • 完整保留 EXIF / IPTC / 相机元数据，支持一键移除 GPS 位置隐私、写入版权署名，以及九宫格文字/图片水印与并发批量导出。
补充规格与说明

支持单张与有界并发批量导出，提供 Gain-Map HDR JPEG、10-bit PQ HEIC、16 位广色域 TIFF/PNG、导出端 2x 超分、EXIF/IPTC/GPS 隐私控制、文字与图片九宫格水印及固定导出目录。

零 Python 原生 AI 与 5 槽位模型中心

无需折腾环境即可开箱使用原生端侧 AI，也能按需叠加 Core ML 加速或本地多模态大模型。

  • 开箱即用的纯 Swift 原生工作台：内置 NativePhotoPlanner（像素统计 + 意图解析 + 自动生成局部蒙版）、参考图一键反解可编辑参数对色，零 Python 依赖即可预览与应用。
  • 5 槽位 Core ML 模型中心：在应用内统一管理 LaMa 消除、天空分割、DepthAnythingV2 景深、AI RAW 降噪 与 AI 2x 超分 五个槽位；未安装时全部提供高质量零模型算法自动兜底。
  • 可选进阶 Qwen3-VL（MLX）模式：如需自然语言开放指令理解，仍可按需单独安装约 3.1 GB 底模配合内置 1.3 MB 微调适配器使用；所有建议均先经双图预览确认，照片全程不离开本机。
补充规格与说明

原生 AI 工作台、参考图对色、零模型深度/天空分割、PatchMatch 消除、YCoCg RAW 降噪与 2x 超分全部内置即用；Core ML 加速槽位与可选 Qwen3-VL MLX 底模的安装方法见帮助页 AI 与模型中心说明。

开发验证与行为约束（非独立测试）

4.1 换上了新的微调权重：同一批 301 条受控验证指令上，首次严格完成率从 51.8% 提升到 94.0%。换的只是随应用附带的 1.3 MB 适配器，底模不用重新下载。这组成绩来自开发验证集，不是独立测试，也不代表审美。

说清楚就照做

「只裁去左右各 5%、保留完整高度」这类要求由代码直接计算范围，不交给模型估。自动裁切会先验证尺寸与保留面积，方案不合法就退回重试一次，两次失败不应用。

说保留就真的保留

明确要求「别动曝光」「白平衡保持原样」时，这些滑杆会从模型可写字段里移除，解码后再复核一次。全局与局部混合的要求照样支持。

先看，再决定

生成的方案先出预览，确认后才写入；一次应用对应一次撤销。局部效果会用真实渲染像素核对方向，不符合要求会重试或拦截。

原生引擎、双语与文件兼容

以 Apple 芯片原生架构构建，与 Mac 的工作方式保持一致。

  • Swift、Metal（20 个 Compute 计算内核）、Core Image、Vision、Core ML 与 AppKit；浅色、深色外观及应用图标自动跟随系统。
  • 界面支持跟随系统、简体中文和 English，1,017 条词条即时切换，无需重启。
  • 编辑写入 .rawforge.json 与可选双向 Adobe .xmp 旁档，兼容旧版 RawForge 旁档与已有预设，原始文件零修改。
补充规格与说明

ARW / CR3 / NEF / RAF / DNG 等主流 RAW，另支持 HEIF / HEIC / HIF、JPEG、PNG、TIFF、AVIF。

界面语言可选「跟随系统 / 简体中文 / English」，即时切换、不用重启。菜单、参数、表单、模型中心与提示共 1,017 条词条，工具提示与无障碍标签同步切换。

非破坏性 RAW 照片编辑器，为 macOS 26+ Apple 芯片而写。16-bit 扩展线性浮点 Metal 管线与端侧 AI 全部跑在你的 Mac 上，编辑结果写入原图旁的旁档文件，原始文件一个字节都不会被改动。

石墨与香槟金

界面以中性石墨灰面板打底，香槟金只点在「选中」与「编辑态」两处，其余全部克制。工整来自严格网格：固定行高节奏、等宽数字对齐、发丝分隔线。

克制的金色

金色不装饰，只表达状态：选中环、滑杆填充、胶片卡、导出主按钮。看到金色，就是在编辑。

严格网格

26 / 27 / 34 px 固定行高节奏，16 px 统一内边距，数值列右对齐等宽。密度高而不乱。

蒙版可视化

参考线是 1 px 白色虚线，控制点用颜色区分职责：线性渐变端点为青、中心为白、旋转柄为琥珀；径向渐变为黄。看到颜色就知道能拖什么。

端点：控制渐变宽度
中心：整条平移
旋转柄：改变方向
径向渐变：椭圆与羽化边界

04功能

把高频能力做全做透。

不堆砌功能。所有调整写入原图旁的副档，原始文件永不修改，随时可以退回原点。

RAW 解码

ARW / CR3 / NEF 等主流 RAW，另支持 HEIF / HEIC / HIF、JPEG、PNG、TIFF、AVIF。

影调与色彩

曝光、对比、高光、阴影、白色与黑色、纹理 / 清晰度 / 去朦胧、白平衡灰点吸管、HDR；五通道色调曲线、HSL 混色、颜色分级、黑白、校准。

胶片 CLUT 模拟

HALD CLUT 加载，含 Kodak 2383 / 2393 印片模拟，64³ 立方体重采样，强度可调。

局部蒙版

线性与径向渐变、画笔、颜色范围、亮度范围、选择主体、选择人物、主体抠图、深度涂绘，共九种。每个蒙版带独立调整栈，可反转、复制、删除。

批量工作流

多选同步调整、恢复快照、命名预设、命名快照，以及多重曝光合成。

专业导出

8 位与 16 位 TIFF 多色域、长边缩放、文字与图片水印九宫格叠加、固定导出目录。

A / B 双布局工作区

4.0 重做的主窗口：A 列表逐张精修，B 胶片连续选片。工具条与系统交通灯共用中线，列表与检查器宽度可拖，切布局不打断编辑。

本地 AI 修图

用中文描述想怎么改，模型给出全局滑杆与局部蒙版建议，先预览再应用。推理在本机完成，照片不上传。属实验性功能，模型需单独安装。

中英文界面

界面语言可选「跟随系统 / 简体中文 / English」，即时切换、不用重启。菜单、参数、表单与提示共 668 条词条，工具提示与无障碍标签也会跟着变。

04本地 AI · 实验性

用中文说，让它改。

在调整面板顶部打开 AI 修图，直接写要求 —— 比如「压暗天空，人物提亮一点，绿色别太艳」。模型只输出参数，不生成、不替换你的照片。

4.1 换上了新的微调权重：同一批 301 条受控验证指令上，首次严格完成率从 51.8% 提升到 94.0%。换的只是随应用附带的 1.3 MB 适配器，底模不用重新下载。这组成绩来自开发验证集，不是独立测试，也不代表审美。

说清楚就照做

「只裁去左右各 5%、保留完整高度」这类要求由代码直接计算范围，不交给模型估。自动裁切会先验证尺寸与保留面积，方案不合法就退回重试一次，两次失败不应用。

说保留就真的保留

明确要求「别动曝光」「白平衡保持原样」时，这些滑杆会从模型可写字段里移除，解码后再复核一次。全局与局部混合的要求照样支持。

先看，再决定

生成的方案先出预览，确认后才写入；一次应用对应一次撤销。局部效果会用真实渲染像素核对方向，不符合要求会重试或拦截。

AI 需要单独安装底模（约 3.1 GB，首次安装需联网），随应用附带的小型适配器约 1.3 MB。不安装模型也能正常使用全部常规编辑功能。这一功能仍属实验性：细节理解、局部调整与自动构图都可能误判，请以预览为准。安装步骤 →

05安装

四步就能开始修图。

Phos 目前没有做 Apple 公证，所以首次打开需要手动放行一次，之后不会再问。这是 macOS 对所有未公证应用的统一处理，不是 Phos 独有的问题。

下载并打开磁盘映像

点页面上的「下载 macOS 版」按钮，或直接访问 这个直链，下载 Phos-macOS-apple-silicon.dmg，双击打开。

拖进「应用程序」

映像窗口里把 Phos 拖到旁边的「应用程序」文件夹，然后弹出映像即可。

首次打开时放行

Phos 是本地签名、未做 Apple 公证，所以第一次会被拦一次。双击 Phos，点弹窗里的「完成」关掉它，然后立刻打开「系统设置 → 隐私与安全性」，滚到最下面点「仍要打开」。

那个按钮在弹窗出现后大约一小时就会消失，所以要马上点。之后双击就能正常打开了。

嫌麻烦就用一条命令

在「终端」里执行下面这行，可以直接去掉隔离标记，之后双击即可打开：

xattr -dr com.apple.quarantine /Applications/Phos.app

06常见问题

你可能想问的。

价格、格式支持、隐私与安装 —— 关于 Phos 最常见的疑问都在这儿。

Phos 收费吗？

免费，开源，采用 MIT 协议。没有订阅、没有内购、不需要注册账号，也不存在「专业版」的区分。

支持哪些 macOS 版本和机型？

需要 macOS 26.0 或更高版本，且是 Apple 芯片（M 系列）的 Mac。3.2.5 起最低系统从 15.0 提高到 26.0，旧系统请继续使用 3.2.4。当前只提供 Apple 芯片构建，Intel 机型暂不支持。

支持哪些相机的 RAW 文件？

走 macOS 系统内置的 RAW 解码（Core Image 与 ImageIO），凡是系统「预览」能打开的 RAW 都能编辑 —— 覆盖佳能 CR2 / CR3、尼康 NEF、索尼 ARW、富士 RAF、Adobe DNG 等主流格式。

更新的机型能否支持，取决于你所用的 macOS 版本是否已内置该机型的解码器。

会上传我的照片吗？联网是做什么的？

不会上传。照片全程在本机处理，没有云端、没有账号、没有遥测。

唯一的联网行为是启动时向官网查一次最新版本号，请求里不含任何关于你、你的照片或这台 Mac 的信息。

和 Lightroom 有什么不一样？

Phos 是本地优先：不订阅、不云同步、不做移动端，专注把 RAW 解码、影调与色彩、胶片 CLUT 模拟、局部蒙版和批量导出做扎实。

适合希望照片完全留在自己机器上的个人摄影流程。

第一次打开被 macOS 拦住了怎么办？

这是所有未做 Apple 公证的应用都会遇到的统一提示，不是 Phos 独有的问题。双击 Phos → 点弹窗里的「完成」→ 打开「系统设置 → 隐私与安全性」→ 滚到底部点「仍要打开」。

也可以在「终端」执行 xattr -dr com.apple.quarantine /Applications/Phos.app 一次性去掉隔离标记。

支持批量处理吗？

支持。可以批量导入、把一张照片的调整同步到其他照片，并批量导出（含导出水印）。

有 Windows 或 iPad 版吗？

macOS 版是主线。Windows 另有一个实验性移植版（4.0.1，从 macOS 4.0.1 的源码移植），与 macOS 分开维护：Apple 的 Vision 与 Core Image 换成了本地实现，不含本地 AI 修图，也未做代码签名。可以在 下载区 获取。

iPad 版仍在可行性评估阶段，没有可发布的时间表。

怎么反馈问题或参与开发？

到 GitHub 仓库提 Issue 或 Pull Request 都可以。项目用 Swift 编写，基于 Core Image、Vision 与 AppKit。

安装前请确认

· Apple 芯片（M 系列）的 Mac，macOS 26 及以上
· 已安装 arm64 版 Python 3.11（python.org 下载页，选 macOS 64-bit universal2 installer）
· 至少 8 GB 空闲磁盘（权重约 3.1 GB，另加 Python 与 MLX 依赖）
· 首次安装需要联网，要能访问 pypi.org 与 huggingface.co
· 16 GB 统一内存是本机测试配置，8 GB 未验证

三步装好

  1. 装 Python 3.11。从上面的链接下载安装包，双击装完。终端里执行 python3.11 --version 能打印出版本号，就说明装好了。
  2. 解压，双击「安装模型.command」。如果 macOS 提示「无法验证开发者」，右键点这个文件 →「打开」→ 再点一次「打开」。会弹出一个终端窗口开始安装。
    国内网络连不上 Hugging Face 的话，改双击「国内网络安装.command」，见下一节。
  3. 等它跑完。先装固定版本的 MLX 依赖，再从 Hugging Face 下载模型（约 3.1 GB，看网速），最后逐个文件校验 SHA256。看到「安装并校验完成」就是好了。

国内网络怎么装

安装脚本默认从 huggingface.co 拉模型、从 pypi.org 拉依赖。这两个地址在部分网络下会连不上或极慢，尤其是 Hugging Face。不用代理也能装。

最简单的办法：解压后双击「国内网络安装.command」（4.0.1 起随包提供）。它会把两个下载源换成 hf-mirror 与清华 PyPI 镜像，其余流程和普通安装完全一样，不需要碰终端。

想手动跑、或者想自己指定别的镜像，就在解压后的文件夹里打开终端（文件夹上右键 →「服务」→「新建位于文件夹位置的终端窗口」），粘贴执行：

HF_ENDPOINT=https://hf-mirror.com \
PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple \
python3.11 install_model.py

镜像只影响从哪里下载，不改变校验：模型文件仍会按清单逐个比对 SHA256，镜像上的文件只要有一个字节不对就会报错停下，不会装进坏文件。想先确认镜像通不通，直接打开 hf-mirror.com 上的模型页 看看。

Python 安装包从 python.org 下得慢的话，可以用华为云镜像：mirrors.huaweicloud.com/python，挑 3.11.x 的 macOS universal2 安装包。

装完怎么用

默认装在 ~/Library/Application Support/Phos/MLX，Phos 会自动找到它 —— 打开任意照片，在调整面板顶部点「AI 修图」就能用，不需要再做配置。

想装到别处：终端执行 python3.11 install_model.py --environment /绝对路径/新的Phos-MLX，装完后在应用里走「AI 修图 → 选择模型环境」，选那个同时包含 .venv 和 model 的外层文件夹。

检查是否装好：python3 install_model.py --verify-only。想卸载，直接删掉那个文件夹即可。

常见问题

提示「请先安装 Apple Silicon Python 3.11」

要么没装，要么装成了 Intel 版。从 python.org 重新下载 universal2 安装包；装完在终端跑一次 python3.11 --version 确认，再双击「安装模型.command」。

下载到一半失败了怎么办

脚本不会覆盖已有环境，中断后现场会保留。换一个能稳定访问 Hugging Face 的网络，重新双击「安装模型.command」即可；也可以先用 --environment 指定一个全新的空目录重装。脚本不会自动切换到未审核的镜像站。

我只下载了模型文件，为什么还是用不了

权重和运行环境是两件事。只把 .safetensors 放进目录不会有 MLX 依赖，必须由这个安装包装好 .venv。两者都齐了，Phos 才能启动本地推理服务。

装好后能移动或复制那个文件夹吗

不建议移动。里面的 .venv 记录的是绝对解释器路径，换位置会失效。要换地方，用 --environment 重新装一份。

AI 会把我的照片传到哪里吗

不会。推理在本机的 127.0.0.1 上跑，照片不离开这台 Mac。只有安装阶段下载模型和依赖时需要联网。

底模是 mlx-community/Qwen3-VL-4B-Instruct-4bit（固定版本 2fd8dacb…；国内镜像见 hf-mirror），许可为 Apache-2.0，来源说明与许可原文随应用内 PhotoAIAdapter 目录一并保留。Phos 的学术用途声明不改变第三方模型的授权条件。

Windows 版 · 实验性移植

  • Phos-4.0.1-Windows-x64.zip323 MB · Windows 11 x64

从 macOS 4.0.1 的源码移植而来，与 macOS 版分开维护，版本号也不同步。解压后双击根目录的 Phos.exe，它必须和 app\ 文件夹放在同一目录。

它和 macOS 版不完全一样。Apple 的 Vision 与 Core Image 换成了本地实现（MODNet / BiRefNet / OpenCV / D3D11），主体分割、边缘和色彩结果可能有差异；不含本地 AI 修图；也没有 macOS 4.1 那一轮的界面更新（高级编辑、玻璃统一、裁剪热区、自动水平）。

未做代码签名，首次运行会被 Windows SmartScreen 拦下，需要点「更多信息 → 仍要运行」。完整的差异与已知限制见 发布说明。

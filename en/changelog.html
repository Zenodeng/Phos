v4.7.2

Latest · Mask Fixes & Core ML Upgrade
2026-11-25GitHub Release ↗

Fixed macOS mask selection overlay solid-red flooding and rotated radial mask mirroring, added native MLMultiArray Core ML tiled inference, and shipped one-click installers for all 5 Core ML slots.

  • Fixed solid-red mask overlay flood on macOS: moved mask overlay tinting into Core Image Engine.maskOverlayImage with true premultiplied alpha, eliminating the macOS NSHostingView failure when applying SwiftUI .mask(.luminanceToAlpha()).
  • Fixed rotated radial gradient mirroring & handle axes: matched rotation sign between Metal/Core Image rendering and canvas overlay guides, fixed swapped rxD/ryD handles, and removed the inert Mask Feather slider for Linear Gradient and Luminance Range masks.
  • Native MLMultiArray Core ML inference: upgraded CoreMLSkyEngine (U²-Net sky) and CoreMLImageModelManager (SCUNet denoise / RealESRGAN 2x super-res) to support both Image and MLMultiArray (NCHW/NHWC, FP16/FP32) models with dynamic tile sizes and Hann-window blending.
  • One-click installers for all 5 Core ML slots: added sky, denoise, 2x super-resolution and all-in-one scripts (install_*_model.sh) wired directly into the in-app Model Hub, all supporting HF_ENDPOINT mirrors.

v4.7.1

Hotfix
2026-11-24GitHub Release ↗

Fixed macOS 26/27 icon-menu text fallback in Boolean Sub-Masks and hardened right-inspector leading-edge layout.

  • Native NSMenu icon triggers for Boolean Sub-Masks: replaced icon-only SwiftUI .borderlessButton menus in the mask panel with a lightweight native NSMenu trigger, preventing SF Symbol names (plus.square, minus.square, square.on.square) from rendering as literal text and overflowing the inspector.
  • Strict leading-aligned inspector widths: enforced leading alignment and compact sizing across GroupBox, InspectorPane, MaskPane and MaskEditingControls so 248–304pt widths never clip on the left.
  • Polish & localization: removed duplicate chevrons in Auto Tone scene and Reference view menus; added missing English strings for Subtract/Intersect (1,017 validated UI translations total).

v4.7.0

On-Device AI Milestone
2026-11-23GitHub Release ↗

Zero-Python on-device AI suite: Reference Color Match, any-RAW monocular depth optical bokeh, RAW denoise & export 2x Super Res, Smart Culling and 5-slot Model Hub.

  • Reference-to-Editable-Parameters Color Match: solves any reference still into editable Phos sliders via OKLab/OKLCH 7-quantile luminance, 3-way color grading, 8-band HSL and coordinate descent, with 0–150% strength and skin protection.
  • Any-RAW Monocular Depth & Physical Optical Bokeh: built-in Vision saliency + person + perspective zero-model depth plus optional Core ML DepthAnythingV2, click-on-canvas focus sampling, depth heatmap, 5–8 polygon blades, linear HDR specular boost and cat-eye vignetting.
  • Non-Destructive RAW Denoise & Export 2x Super Res: Metal linear YCoCg edge-preserving denoise and export-only Lanczos 2x + structure-tensor sharpening (or tiled Core ML models) with zero bloated DNG copies and a preserved 1:1 preview contract.
  • Smart Culling, Burst Clustering & Bilingual Semantic Search: EAR eye-closure detection, focus sharpness scoring, burst-best picks and visual similarity sorting.
  • Pure-Swift Native AI Workbench & 5-Slot Model Hub: bundled NativePhotoPlanner and unified Core ML Hub (lama, sky, depth, denoise, superRes); fixed a SwiftUI out-of-bounds crash when removing Point Color swatches.

v4.6.0

Masks, Multi-View & XMP
2026-11-23GitHub Release ↗

Added 8-part portrait segmentation, Auto Mask pressure brush, full multi-view culling, bidirectional Adobe XMP and 82 lens profiles.

  • Complete masking: added body skin, eyebrows and clothes segmentation plus upgraded zero-model / Core ML sky segmentation; added Auto Mask edge snapping & tablet pen pressure; interactive Add/Subtract/Intersect sub-masks, local Tint/Whites/Blacks, expandable local Curve Editor and local OKLCH Point Color.
  • Interactive retouching: clean source suggestion, on-canvas spot and source handle dragging, dual-ring hover brush preview and H / Delete shortcuts.
  • Multi-view & browser: Grid (G), Compare (C), 2–4 Up Survey (N) and Reference (⇧R) views; recursive subfolder scanning, keywords and camera/lens filters.
  • XMP & 82 lens profiles: full bidirectional Adobe XMP sidecars with persistent auto-sync, Lightroom .xmp preset import with 0–200% strength scaling, and 82 built-in lens profiles.

v4.5.0

16-bit Metal Engine
2026-11-22GitHub Release ↗

Moved the core rendering pipeline to 16-bit extended linear floating-point Metal with EDR/HDR preview, OKLCH Point Color, LaMa remove and HDR export.

  • 16-bit Metal / EDR pipeline: switched to extendedLinearSRGB / .RGBAh GPU compute kernels with EDR preview canvas and J highlight/shadow clipping alerts.
  • Pro tone & color: added AgX contrast pivot/rolloff, 14-stop Guided Filter toning, bidirectional whites/blacks, OKLCH HSL, dedicated Point Color swatches and grain roughness.
  • Retouch & metadata export: added Heal (Poisson), Clone and Remove (4-level PatchMatch + optional Core ML Big-LaMa); EXIF/IPTC preservation, GPS privacy strip, Gain-Map HDR JPEG, 10-bit PQ HEIC and 16-bit Display P3 export.

v4.4.0

Lens UI & Async LUTs
2026-10-31GitHub Release ↗

Added before/after lens comparison and an 8-way reference grid, moved LUT directory scanning off the main thread, and migrated updates to zenodeng.com.

  • Lens correction workflow: instant before/after bypass toggle, 8-way straightness grid, explicit profile provenance and bundled starter profiles.
  • Background LUT scanning: scanning film LUT directories runs asynchronously with live status without blocking UI interaction.

v4.3.0 / v4.2.0

Bilingual & Liquid Glass
2026-10-21 – 10-22GitHub Release ↗

Instant Follow-System / Chinese / English language switching, native macOS 26 Liquid Glass workspace surfaces, full-edge crop dragging and Vision Auto Level.

  • Instant bilingual UI: switch languages without restarting or losing edit state, undo history, presets or snapshots.
  • Native glass & crop precision: unified native glass chrome with Reduce Transparency fallback, full-edge crop drag zones and on-device Vision horizon leveling.

v4.1.0 / v4.0.0

Workspace & Optional VLM
2026-10-17 – 10-18GitHub Release ↗

Rebuilt the main window around A Immersive / B Filmstrip layouts and introduced optional local Qwen3-VL MLX editing with a bundled 1.3 MB fine-tuned adapter.

  • A / B dual layouts: one shared edit state and undo stack across list editing and bottom filmstrip culling, with adaptive light/dark icons.
  • Optional local VLM: localhost-only 127.0.0.1 MLX inference with per-file SHA256 verification and mainland China mirror helper script.
